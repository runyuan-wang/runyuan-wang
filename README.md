## 🌌 Agent & Open Source · 开源共建

- 🌠 **[LingTai 灵台](https://github.com/Lingtai-AI/lingtai-kernel)** — Agent OS。官方协作者 Outside Collaborator（kernel & TUI，triage 权限），**45 PR / 13 merged**，覆盖 daemon 调度、安全策略与 token cache
- 📖 **[book-to-skill-distillation](https://github.com/runyuan-wang/book-to-skill-distillation)** — 把厚书与长 PDF 蒸馏成 Agent 原生 Skill · ⭐10，我最受欢迎的仓库
- 🤝 也在 [agent-infra-foundation](https://github.com/agent-infra-foundation)（Owner）、[Ephemeral-AI-Lab](https://github.com/Ephemeral-AI-Lab)（Member，layerfs）和 [NoKV-Lab](https://github.com/NoKV-Lab) 参与 Agent 基础设施共建 | Also building agent infrastructure with these communities

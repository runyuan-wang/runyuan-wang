## 🌿 我在做什么 · What I Build

我在医院临床营养科一线工作，同时把国家卫健委食养指南、临床营养实践和创造力方法论，蒸馏成一个个人人可自由使用的 **AI Skill / Agent**。全部公益开源。

I work frontline in a hospital clinical nutrition department, and distill official dietary guidelines, clinical practice, and creativity methodologies into **AI skills & agents** that anyone can use for free.
